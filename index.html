Features

🔍

Google Drive Search

Full-text search across all your Drive files. Find documents, spreadsheets, and presentations instantly without leaving Slack.

✏️

Google Drive Editing

Read, write, and manage Google Drive files directly from Slack. Create documents, update content, and organize your drive.

💬

Smart Q&A

Ask questions and get answers powered by LLM. Handles complex queries with context-aware responses.

🌐

Web Search

Search the web and fetch page content without leaving your Slack workspace. Real-time information at your fingertips.

📚

Skills System

Extend the agent with custom skills. Drop a SKILL.md in the workspace and the agent learns new capabilities automatically.

⚙️

File & Code Execution

Read, write files and execute code in isolated workspace per channel.
